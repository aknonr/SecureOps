test-owned database. It does not migrate, clear, globally refresh or stale older
SQL fixtures. Prior isolated SQL refresh tests are reused only for their actual
source scope; this is not a newly executed complete SQL suite.

payloads, corporate configuration, migrations and grants are unchanged.
